# Oi, eu sou a Carina 😎

![https://github.com/carinadourado/carinadourado/blob/main/header_git.gif?raw=true](https://github.com/carinadourado/carinadourado/blob/main/header_git.gif?raw=true)


Sou jornalista de dados, com master em **Jornalismo de Dados, Automação e Data Storytelling** ([Insper](https://www.insper.edu.br/pos-graduacao/master-em-jornalismo-de-dados-automacao-e-data-storytelling/)) e também especializada em **Relações Internacionais** ([UnB](http://irel.unb.br/)) e **Artes Visuais** ([Senac](https://www.ead.senac.br/pos-graduacao/gestao-cultural-cultura-desenvolvimento-e-mercado/)). Trabalho na [TV Brasil](https://tvbrasil.ebc.com.br/) desde 2005, como repórter do premiado programa Caminhos da Reportagem.

Aqui você encontra alguns códigos e projetos em desenvolvimento. Tem Python, tem HTML, CSS e Javascript. Criei o projeto **O Que Jair Tá Fazendo** - https://github.com/oquejair - para acompanhar e fiscalizar o que o então presidente do Brasil Jair Bolsonaro estava fazendo durante a presidência. O projeto funcionou entre 2021 e 2022. Além disso, após o fim do mandato, criei um site de visualização dos dados da agenda: http://oquejair.github.io
